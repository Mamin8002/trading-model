## 2. Walk-forward-валидация (chronological, expanding window, embargo)

Схема: стартовое обучение 60% → 8 последовательных тестовых окон; переобучение на каждом окне. Embargo: в обучение попадают только строки, чья метка полностью известна до начала окна (t + (H+1)·interval ≤ test_start) — утечка будущих данных исключена.

## 5. Ограничения

- Accuracy выше baseline **не означает прибыльность**: комиссии, спред и слиппедж не учитывались.
- Реалистичная оценка: среднее |движение| бара ≈ 0.0941%; ожидаемый валовой выигрыш на сигнал ≈ (2·acc−1)·E|Δ| ≈ **0.00090%** при acc=0.5048. Комиссия спот-сделки round-trip (taker ~0.1%×2) ≈ 0.2% — на два порядка больше. Модель пригодна для исследовательского мониторинга и демонстрации, но не для комиссионной торговли на этом горизонте.
- Задача предсказания знака 5-минутного движения близка к эффективному рынку: реалистичный уровень — чуть выше 50%.
- Сырые уровни цен (набор `raw`) не экстраполируются деревьями за пределы обучающего диапазона — при дрейфе цены качество деградирует; walk-forward-переобучение обязательно.
- Выбор feature_set по тем же walk-forward-окнам, на которых он сравнивается, даёт небольшой оптимизм (selection bias).
- Результат зависит от рыночного режима в периоде обучения; рекомендуется периодическое переобучение и мониторинг live-качества.
